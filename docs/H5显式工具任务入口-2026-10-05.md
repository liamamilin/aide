# H5 显式工具任务入口

更新日期：2026-10-07。候选版本仍为 `1.5.0`，本阶段在 H1–H4 的唯一运行时上接入用户入口，没有新增 Agent 或另一套工具循环。

## 如何使用

1. 选择任一内置或自定义对话 Agent 和本次任务使用的模型，在输入区点击“工具关闭”。
2. 按需要勾选 Bash、联网搜索，或两者同时启用。Bash 选择有效工作目录及命令策略；搜索选择 Parallel 或 Exa，密钥在“设置 → 联网搜索”中管理。
3. 点击“启用工具”，本机模型检查通过后发送任务。输入区显示实际任务模型、授权工具、目录和命令策略。
4. 复杂命令在执行卡片中批准或拒绝；生成期间可停止。任务答案的“重新执行”会询问是否重新调用工具，可能再次产生文件变更或搜索费用。

设置中的“允许对话 Agent 启用工具”只控制入口是否可用，**不等于已经授权执行**。首次使用时默认关闭工具；启用后设置会沿用到新建/切换对话、其他 Agent 和重启。关闭工具同时清除默认选择，后续对话保持关闭；未授权的聊天与快捷动作保持空工具、单轮执行。所有对话 Agent 的工具能力使用同一运行时，保留各自角色提示词，详见 [对话 Agent 工具通用化](对话Agent工具通用化-2026-10-06.md)。当前对话中的 Action 也不会继承工具授权。

当前工具任务的模型跟随顶栏选择，不使用另一个固定模型或 Agent profile 的模型替代。上下文、输出与采样参数跟随设置；角色专用配置可覆盖思考、温度和输出。普通聊天保留原有配置解析。搜索任务建议明确写“搜索网页……”，H0 的模糊搜索路由失败仍是保留的模型能力限制。

## 授权、配置与取消

- 同一角色、同一对话的后续轮次保留授权；切换模型保留工具勾选，但取消旧任务并在下一次发送检查新模型。
- 工具选择保存为应用默认配置。新建、切换或加载历史会话、切换 Agent 和重启都会沿用；每个作用域创建属于当前角色的新快照，不继承历史任务、命令批准或能力检查。修改工具/搜索配置影响下一次任务。详见[工具设置继承](工具设置继承-2026-10-07.md)。
- Bash 的策略按工作目录记忆；每次 run 保存不可变目录和策略快照。启动前核对目录存在及文件系统身份，失效时拒绝执行，不回退到应用目录。
- 可自动执行的只是 H2 明确允许的工作区只读字面量命令；其余命令需要确认，也可选择全部确认。工作目录不是 OS 沙箱，复杂命令获准后仍可能访问其他位置。
- 运行中的快照不随设置变化。授权变更影响下一次任务；停止、主动隐藏工具任务窗口、切换会话、角色或模型会取消当前任务。旧工具 Worker 收尾期间不能启动第二个工具任务。
- 模型检查异步执行，可停止。失败、超时、关闭窗口或切换会话不会落库用户消息，不会调用工具；保留草稿和待发送图片。检查阶段持有附件，转交 Worker 后才释放检查引用。

## 模型准入与预算

启用时及每次发送、重新执行前读取本机 `/api/version`、`/api/tags`、`/api/show`。只允许 HTTP loopback 地址，禁止远程服务、凭据 URL 和重定向；全检查限时 5 秒，每个响应最多 1 MiB。元数据请求不调用模型生成或付费搜索。

核对当前所选模型的安装身份、completion/tools 声明及可用思考控制，记录当前服务版本和 digest。模型参数使用全局设置及角色专用配置的有效值，与授权面板保持一致；不再固定为 8192/1024/temperature=0。思考设置按本次新鲜能力声明解析，不支持时回退模型默认并提示。详见 [工具模型参数一致性修复](工具模型参数一致性修复-2026-10-05.md)。次数默认最多 8 轮模型、16 次工具、6 次搜索，可在设置 → 工具执行分别调整为 1–99；活动时间仍为 5 分钟。详见 [工具次数与搜索来源设置](工具次数与搜索来源设置-2026-10-05.md)。显式上下文上限不足时拒绝任务。

能力检查不等于行为验收。H0–H3 的 9B 行为与预算结论仍作为历史证据保留，不能沿用到所有模型；不再用固定 9B digest 或服务版本阻止选择其他模型。当前修复与 27B 验证见 [工具授权与模型跟随修复](工具授权与模型跟随修复-2026-10-05.md)。检查与生成之间仍无法保证模型标签不会被外部替换，也不构成系统安全沙箱。

任务请求包含 num_ctx、num_predict、temperature、top_p、top_k、repeat_penalty 六项有效参数。模型声明上下文小于配置值时拒绝；输出上限必须为输入与工具结果保留空间，检查失败保留草稿。修改生成设置或角色配置时取消未完成的参数检查，保留会话内授权；下一次发送检查新值，正在运行的请求仍使用原快照。工具输出沿用 H2/H3 有限截取，等待命令确认不计入活动预算；单个 Bash 调用的超时上限为 120 秒。搜索次数限制用于控量，不能保证固定金额。

## 过程、答案与历史

每轮模型输出有固定步骤卡片，流式正文不会在工具调用后消失；工具卡片按顺序接在模型步骤后。最后一轮模型卡片原位成为最终回答，不额外生成重复气泡。思考区默认折叠，与正文分开。

最终回答沿用 Markdown、复制、答案版本、来源编号和选中文字朗读。中间步骤保留为过程文字，不能冒充最终答案。停止或失败保留已完成步骤和原因。

工具任务“重新执行”先确认，再检查当前授权、原任务角色与模型，创建新 run；原用户消息不重复落库，旧原始工具结果不重放。普通答案“重新生成”始终按原空工具路径执行，即使当前会话已经启用工具。历史读取和版本切换均不执行命令。

运行审计保存实际授权工具、目录/策略、模型准入身份和来源；沿用 [H4](H4运行审计与历史恢复-2026-10-05.md) 的脱敏、30 天 payload 清理、删除和只读历史。可见过程卡片同步到期清理，最终答案保留。
