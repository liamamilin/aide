# Aide 个人电脑入口开发计划

日期：2026-10-26。依据：[设计草案](Aide个人电脑入口设计-2026-10-26.md)。工具注册表重构已完成并提交（`llm/tool_registry.py`）。

## 顺序原则

先做不依赖模型的确定性路径，再做会改变现有行为的 Agent 工具默认开启。后者牵涉每次发送前的模型准入检查，放在最后，且不在无人确认时改动 `main.py` 的发送流程。

## 进度（2026-10-26）

- M1 完成：`ai_desktop/desktop/`（runner、search、opener、resolver、tools）。真实 `mdfind` 只读验证通过：“备忘录”→Notes、“微信”→WeChat、“方案”→文档；真实 `open` 未在自动化中调用。
- M2 完成：`ui/candidate_panel.py` 与对话框接线。Enter 仅在用户用 ↑↓ 或点击选中候选后才打开，否则照常发送；历史浏览期间不查询。
- M3 完成：`find_apps`、`find_files`、`open_path` 已注册，只在已通过准入的工具运行中提供（`config.DESKTOP_TOOLS_ENABLED`）；`.app` 仅在标准应用目录内才直接启动，其他位置只在 Finder 中显示；工具卡片标题、系统提示已更新。测试环境默认关闭这两个开关，避免真实查找。
- M4 未做，等待用户决定。

## 已确认的技术事实（本机验证）

- `mdfind` 支持多个 `-onlyin`；`kMDItemDisplayName` 是本地化名称（`/System/Applications/Notes.app` 为“备忘录.app”），`kMDItemAlternateNames` 保存英文名，所以一次谓词查询即可同时匹配中文与英文应用名。
- `AppKit`、`Foundation` 可导入，且已在 `scripts/aide.spec` 的 hiddenimports 中；本阶段仍使用 `/usr/bin/mdfind`、`/usr/bin/open` 绝对路径加列表参数，不经过 shell。
- 默认文件搜索范围：`~/Documents`、`~/Desktop`、`~/Downloads`，不含 `~/Library`。这是本阶段选定的默认值，设置项后续再加。

## 安全约束

- 打开文件会执行的类型（`.command`、`.sh`、`.pkg`、`.terminal`、`.workflow`、`.scpt`、`.jar` 等）只在 Finder 中定位，不直接打开。
- 只接受绝对路径；路径必须存在。
- 搜索只返回路径与元数据，不读取文件内容，不送入模型。

## 风险与注意

- 解析在后台线程运行，结果带序号，过期结果丢弃，避免 `mdfind` 阻塞界面。
- 工具卡片目前对非 Bash 工具统一显示“联网搜索”，M3 前需修正，否则新工具会被错误标注。
- 系统提示中“本地文件使用 bash”需指向新工具。
