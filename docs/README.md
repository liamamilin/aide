## 当前建议

1. **M1 + M2 / v1.5.0 候选**：请求生命周期、附件、模型能力、历史、窗口记忆、数据库升级和本机候选构建已通过；发布前补系统权限、主题/焦点、真实多屏和覆盖安装验收。
2. **M3 / v1.6**：任务模型配置 F03、快捷动作 F01、桌面宠物 F13.1–F13.4 与 F02.1–F02.5 已完成代码和自动化验收；M3 真实桌面闭环已启动，文件选择与 OCR 主路径已通过。
3. **发布边界**：当前候选已改用本机稳定证书 `AI Desktop Assistant`，仍没有 Developer ID 签名、公证、标签或 GitHub Release；稳定证书用于解决本机 TCC 权限随重建失效的问题，不等同于公开分发签名。
4. **M4 以后**：根据实际使用选择答案版本、收藏、临时会话、桌面偏好、文件上下文；知识库、语音和写回先做限时实验。

## 维护方式

- 每个任务记录待开发/开发中/待验收/已完成、对应提交、验证结果、剩余问题；旧问题不能只改成勾选完成而缺少证据。
- 活跃开发每个工作包/关键验证/阻塞或方案变更更新[开发进度](开发进度.md)，连续开发每 30 分钟追加检查点，结束前保存结果和下一步。
- 产品候选只有通过使用验证并选入里程碑后才进入承诺范围。每个里程碑结束时复核下一组功能，不预设必须把全部候选做完。
- 完成里程碑后同步双语 README、版本和变更记录；年度/日期文档保留为决策历史，新评估在此入口追加。
- 根目录的 `产品化计划.md`、`思考与设计.md`、`开发记录.md` 留作历史参考，当前被 `.gitignore` 忽略；本 `docs/` 文档集作为可跟踪的新入口。
