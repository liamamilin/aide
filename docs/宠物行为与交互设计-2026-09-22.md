# 宠物行为与交互设计

更新日期：2026-09-22。目标是让桌面猫头鹰的反应可预测、低打扰，并让每次鼠标操作都得到明确结果。

## 行为模式

| 模式 | 进入条件 | 画面与节奏 | 离开条件 |
|---|---|---|---|
| 安静待机 | 无任务、无结果、鼠标未悬停 | 身体静止，3.8–7.6 秒随机短眨眼；不主动弹窗、说话或抢焦点 | 鼠标靠近或任务开始 |
| 关注用户 | 空闲时鼠标进入 | 一次轻抬、注视、短眨眼，然后保持稳定；中途移开四步缓动回位 | 鼠标离开、拖动或任务开始 |
| 读取材料 | 正在捕获选区、截图或 OCR 输入 | 读取徽标与轻微侧倾；暂停待机和悬停动作 | 捕获完成或失败 |
| 专注处理 | 大模型正在生成 | 向下看电脑，短暂进入后身体停稳；工作徽标表达持续状态 | 请求完成、失败或取消 |
| 朗读 | 正在生成或播放语音 | 独立声波徽标和轻微节奏；右键首项变成“停止朗读” | 播放结束或用户停止 |
| 结果反馈 | 成功或失败 | 约 1.6 秒的短反馈，随后自动回到待机；完整结果仍在对话/结果气泡 | 计时结束或新任务开始 |
| 隐藏 | 用户主动隐藏入口 | 停止动画和跟踪计时器；菜单栏保留恢复入口 | 用户从菜单栏恢复 |

状态优先级为“生成 > 朗读 > 读取 > 结果 > 待机”。开始任务会收束未完成的悬停动作，防止结果或工作状态结束后突然接上半段旧动画。启用“减少宠物动画”时，眼部切帧、位移、光晕和闪光停止，任务徽标保留。

## 鼠标交互

| 操作 | 结果 | 反馈与边界 |
|---|---|---|
| 单击 | 打开或收起对话 | 不抢其他应用的键盘焦点；鼠标小幅移动仍按单击处理 |
| 按住拖动 | 调整桌面位置，并固定在当前屏幕 | 超过系统拖动阈值才开始移动；拖动时显示抓握光标；松开不会触发“打开对话” |
| 鼠标悬停 | 播放一次关注动作 | 忙碌时不启动悬停动作；持续停留不会反复招呼 |
| 右键 | 朗读选区、截图、最近快捷动作、设置与隐藏 | 忙碌期间禁用会争用材料捕获的动作；朗读中可直接停止 |
| 右键“跟随鼠标所在屏幕” | 开启或关闭自动跨屏跟随 | 默认开启；手动拖动后自动关闭并持久保存，重新开启时立即跟随鼠标所在屏幕 |
| 菜单栏“显示桌面宠物” | 恢复被隐藏的入口 | 保留此前的位置与屏幕跟随偏好 |

朗读选区若为空，会短暂显示宠物错误状态与非阻塞提示；宠物隐藏时使用菜单栏通知，不再弹出模态警告。2026-09-22 的真实窗口首轮验收发现并修复了原模态路径。

闲置宠物只让角色轮廓、短暂抬起的余量和底部阴影接收鼠标，透明四角不再属于窗口命中区域；紧凑悬浮球使用圆形区域。执行任务时暂时使用完整窗口区域，确保状态徽标、光效和成功闪光不会被裁掉。小/中/大三档的可见像素均已与命中区域逐点核对；macOS Cocoa 双窗口命中测试中，透明角落返回下方窗口，角色中心返回宠物窗口。仍需用真实鼠标操作观察长期稳定性。

手动固定屏幕后，跨屏检测计时器停止；重新开启跟随后再恢复计时。屏幕跟随与宠物尺寸、减少动画是独立选择。下一阶段可以根据真实桌面反馈考虑“更安静/更活泼”的可选陪伴强度；在观察到明确需求前，不增加自动提示、自动声音或更多常驻按钮。

## 验收与下一步

- 自动化覆盖点击与拖动区分、拖动阈值、拖动后屏幕固定、右键恢复跟随、偏好持久化、任务对悬停的抢占、减少动画和隐藏计时器停止。
- 真实桌面检查：普通单击与快速拖动、从一块屏幕移到另一块、跨 Spaces、对话窗开合、语音中止、工作中悬停、浅色/深色切换。重点观察是否有意外开窗、位置跳动、动作串帧和焦点转移。
- 透明命中检查：把宠物放在可点击的桌面内容上方，分别点击角色、阴影与四角透明处；角色可打开对话，透明处应由下方应用接收。再检查任务徽标不会被裁切。
- 素材与动作节奏的视觉标准见[宠物动画调研与打磨](宠物动画调研与打磨-2026-09-22.md)。
