## 工作区与设置

设置分为模型与对话、生成参数、联网搜索、工具执行、桌面偏好五页。“工具执行”可选择已存在的目录、只读自动/全部确认策略和显式 PATH。

- 目录展开为绝对 realpath；策略按规范目录分别记忆，新目录默认只读自动，保存后再次打开可恢复。无目录时禁用策略与 PATH；无效目录在保存前给出行内错误，不覆盖之前的配置。
- ExecutionSnapshot 冻结目录、策略、PATH、目录设备与 inode。执行前重新检查目录是否被删除、替换或改成其他链接目标。内部调用者须显式提供快照；应用普通聊天还没有读取设置并启用工具的代码。
- 子进程环境只包含显式 PATH、HOME、TMPDIR、语言与 TERM；不复制父进程中的 API 密钥、代理、BASH_ENV、Python 路径或 Bash 函数。此处是控制环境传递，不保证命令无法从文件读取凭据。
- 工作区规定 cwd 与只读自动访问范围，**不是操作系统沙箱**。经确认的 Bash 以用户身份运行。文件检查与真正打开之间仍可能有竞态，当前没有文件描述符级隔离。

## 三种命令判定

先以受控环境执行 `/bin/bash --noprofile --norc -n -c` 做语法检查；测试确认该检查不会执行命令替换或环境启动脚本。随后只解析足够小的字面参数子集，不实现完整 Bash 分析器。

| 判定 | 当前处理 |
|---|---|
| 无效 | 语法错误、空命令、已识别的直接后台执行等返回有限工具错误，不启动执行进程 |
| 只读自动 | 固定程序路径的 pwd / ls / cat / head / tail / wc，有限选项、明确文件参数、规范路径在工作区内，直接执行 argv |
| 需要确认 | 复杂语法、重定向、管道、展开、解释器、写入、网络、提权、未知选项与越界路径等；全部确认策略也走此分支 |

只读自动不通过 Shell 解释用户命令。文件参数必须已存在且为普通文件（ls 可接受目录）；设备、FIFO、越界链接、无法确认的参数归确认。head/tail 仅开放有限的 `-n` 数值；不把 stdin 读取视作自动允许。语法有效的 heredoc 与复杂表达式交给确认，不因简单字符匹配误判为无效。

分类器不保证识别复杂脚本/其他解释器中的全部后台行为。执行器清理自身进程组；主动脱离该组的进程不在这一保证内。上述范围由实现与测试支持，不能据此宣称本地命令完全隔离。

## 命令确认与生命周期

CommandConfirmation 冻结原始命令、cwd、策略、超时、run/step/request/conversation/tool 身份和指纹。ConfirmationBroker 只接受精确匹配且尚未过期的布尔响应；篡改、旧步骤、重复响应与已使用令牌不会再次执行。

- 等待最多 600 秒；拒绝、过期、取消或无确认接收方均产生明确工具结果。没有 UI 接收方时立即返回 unavailable，避免看不见的等待。
- 确认等待暂停 ActiveBudget，等待时间不占任务 300 秒活动预算；后续模型步骤使用更新后的截止时间。
- 批准后再次检查取消、预算和工作区，随后执行那条原始 Bash 命令；不自动重试、不重放已执行工具。
- 本轮只实现线程安全的确认协议与测试接收方，**没有桌面批准按钮**。下轮需把状态接到 Fluent 卡片，并验证窗口关闭、换会话和停止时的行为。

## 进程和输出

独立进程组、关闭 stdin、并行读取 stdout/stderr；命令超时默认 30 秒，工具契约最高 120 秒。取消、命令/任务截止、大输出和残留子进程均结束受控进程组。启动配置使用 Python 的 cwd/env/DEVNULL/start_new_session 接口，见 [subprocess 官方文档](https://docs.python.org/3/library/subprocess.html)。

stdout 与 stderr 各最多保留 32 KiB 内存，累计读取到 1 MiB 后停止进程组；不保存原始输出文件。回填包含退出码、时长、截断、错误和执行方式的合法 JSON，默认各取 1024 字节摘录；转义后超过 4 KiB 时继续缩减，保证结构未被硬切坏。模型侧只因预算摘录，不以安全脱敏改写含义。运行审计存储、日志脱敏与到期清理属于 H4，本轮尚未实现。
