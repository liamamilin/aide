# Fluent Light 界面迁移

## 范围与原则

按用户要求仅重构表现层。对话、Agent、模型配置、历史、OCR、快捷动作、朗读、附件、窗口大小及 Petdex 切换维持原有信息架构和服务接口。宠物素材、动画播放及桌面命中区域不改动。

采用 `PyQt-Fluent-Widgets==1.11.3` 与 `PyQt5-Frameless-Window==0.8.2`（PyQt5 绑定），固定 `Theme.LIGHT`。不新增导航栏或设置分类。按钮、输入框、下拉框、卡片、菜单、通知、标题栏及窗口按钮均采用组件库。组件自身的圆角、边框、悬停、字体和动画不覆盖；布局留白采用 8 / 12 / 16 / 24px，保留窄窗口和宽屏居中阅读。聊天主体使用中性 `SimpleCardWidget` 与 `BodyLabel`，主要强调色留给发送/保存等主操作，标题与正文不再使用蓝色装饰。

## 实现结构

- `ui/fluent.py`：库组件、固定浅色初始化、窗口后端，以及 Qt 动作/下拉数据/确认结果的窄兼容层。兼容层不绘制控件、不重写组件 QSS。
- `ui/styles.py`：保留控制器的刷新入口，删除原有自定义 QSS 系统。
- 聊天标题栏使用 `FluentTitleBar` 及自带窗口按钮；保留放大到当前屏幕、调整大小、恢复默认与隐藏。附件/更多使用内置 Fluent 图标和菜单。
- 表单使用 `LineEdit`、`PlainTextEdit`、`ComboBox`、`CheckBox`、`SpinBox`、`DoubleSpinBox`。列表行使用库内置卡片，快捷动作使用 `TogglePushButton` 的选中反馈。
- 宠物结果摘要使用真实 `InfoBar`，外围仅负责桌面定位、不抢焦点、点击查看和超时关闭；应用提示也使用 `InfoBar`。需要确认的操作使用库内置对话框。
- 选区朗读、输入框剪切/复制/粘贴使用 Fluent 菜单，同时复用现有文本与动作接口。

## 平台与打包

macOS 使用 `PyQt5-Frameless-Window` 的原生 Cocoa 后端。无屏测试不具备 NSWindow，窗口承载层使用 Qt 无屏后端，仍使用真实 Fluent 组件；原生窗口另外验收。系统文件选择器和系统菜单栏图标保留 Qt/macOS 后端。

分发需要包含 Fluent 字体、QSS、图标资源与依赖许可证，验证冻结程序导入与窗口启动。上游 PyQt-Fluent-Widgets 采用 GPLv3；如进入商业分发，需要按上游许可条件处理。来源：[官方安装文档](https://pyqt-fluent-widgets.readthedocs.io/en/latest/quick-start.html)、[上游包与许可说明](https://pypi.org/project/PyQt-Fluent-Widgets/)。

## 开发进展

1. 已完成依赖安装、组件替换及旧组件样式撤除。
2. 首轮定向交互检查 141 项通过、3 项构造参数兼容性失败；已定位并修订 Fluent `LineEdit` 初始化方式。
3. 全量 **616 passed**，ruff 和差异检查通过。保留两条既有测试收集警告。固定 Fluent Light 后相应更新了旧暗色/QSS 断言，新增非阻塞版本菜单和快捷动作单选的交互回归。
4. 真实 macOS Cocoa 后端下，聊天、设置、历史、Agent 编辑、快捷动作配置、模型配置和 OCR 八类窗口均成功创建；Retina 预览已核对。放大/恢复、隐藏/重开、快捷动作、通知、确认弹窗和菜单打开的短时验证通过。菜单栏验证包含 Context 信号打开路径，真实鼠标右键与多屏/Spaces 仍建议体验验收。
5. 修复迁移特有问题：库的 Cocoa 后端需要保留原生窗口按钮对象；不能继续沿用旧 Qt 无边框标志。Fluent 菜单非阻塞，版本选择改为动作信号连接，宠物暂停状态等待真实菜单关闭后恢复。所有快捷动作按钮采用 TogglePushButton，仅选中的动作使用默认强调色。
6. 首轮冻结程序通过构建与签名，但诊断 JSON 被上游导入推广提示污染。已在 Fluent 导入边界仅屏蔽该标准输出提示，异常和标准错误仍可见；新增独立进程回归，源码版本/OCR JSON 验证通过。未放宽启动检查。
7. 发布预检增加 Fluent 与 Frameless 依赖的 metadata/许可证检查；隔离启动模式实际创建聊天、消息卡片和设置窗口，验证冻结程序的界面路径，随后自动关闭。
8. 最终 `dist/AI桌面助手.app`（1.5.0，约 866MB）已重建，沿用 `AI Desktop Assistant` 稳定证书签名；严格签名校验、发布预检、OCR/英文朗读诊断、原生界面启动、schema 4 初始化及 schema 0 升级备份检查全部通过。包内 16 个相关模块与最终源码一致；Fluent 编译资源（字体、图标、QSS）存在，两项依赖的 metadata 与许可证哈希与本机安装版本一致。

## 体验方式

退出旧应用实例，打开本项目 `dist/AI桌面助手.app`。窗口采用固定 Fluent Light，宠物选择与动画沿用原有设置。此次已完成自动检查和短时原生界面验收；实际鼠标右键、复杂多屏/Spaces 和长时间使用仍需真实体验观察。
