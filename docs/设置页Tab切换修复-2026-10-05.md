# 设置页 Tab 切换修复

日期：2026-10-05。范围仅为设置窗口导航；全 Agent 工具通用化按后续计划另行实施。

## 原因

Fluent `PivotItem.itemClicked(bool)` 点击时发出 `True`。旧绑定为 `lambda i=index: pages.setCurrentIndex(i)`，Qt 传入的布尔参数覆盖捕获的页码，而 `True` 被当成索引 1。因此点击任何 Tab 都显示“生成参数”，顶栏却显示用户选择的 Tab。默认参数不能隔离信号参数。

先加入实际鼠标点击回归再修复，六项新增用例中五项在旧代码上失败，生成参数页点击通过，符合本次报告；此前设置测试覆盖加载、保存和校验，未覆盖五个 Tab 的实际点击。

## 修复

- 移除每个 Tab 的页码点击回调，使用 `Pivot.currentItemChanged(str)` 的路由标识选择对应页面。
- `QStackedWidget.currentChanged` 同步选中 Tab；用户点击和程序切页保持一致，组件对同一项的选择不会重复发信号。
- 页面仅创建一次，切换不保存设置、不重载表单，保留未保存的字段。
- 保留 Fluent 默认样式、动效及原有五页功能和信息结构。
