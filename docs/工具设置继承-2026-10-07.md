# 工具设置继承

## 目标与行为

用户要求工具设置在新建对话和切换 Agent 后自动继承。本轮将 Bash 开关、工作目录、命令策略与搜索服务保存为应用默认工具配置；新建、切换对话、切换内置/自定义 Agent、重启 App 均使用这份配置。点击“关闭工具”清除默认配置，之后的新对话与其他 Agent 保持关闭。

模型始终跟随顶栏与角色模型配置；每次发送仍进行工具能力检查。搜索来源数、超时、模式和运行预算使用当前设置，修改后下一次任务生效。全局“允许对话工具”关闭时不启用；再次打开后恢复已保存的选择。

快捷动作继续只处理文本/图片，不因为默认工具启用而执行工具。恢复历史使用当前默认设置，绝不从历史运行记录恢复授权、模型准入、命令批准或自动重放工具。

## 实现

- 新增 `ToolPreferences`，使用 SQLite 设置键 `default_chat_tools` 保存带版本的非敏感配置，不新增表和 schema 迁移。未保存过配置的旧用户保持工具关闭，不从既有工作目录或搜索设置推断启用。
- 对话与 Agent 切换先停止旧任务、取消待完成的能力检查，再给当前 Agent 创建新的配置快照。保持任务/轮次/命令身份校验，旧批准与旧模型检查无法作用于新任务。
- 工作目录保存原授权时的 device/inode，路径被替换、删除后不会因为切换对话或重启而重新受信；发送时仍检查目录有效性，用户需重新选择工作目录。
- 当前工具面板保存/关闭时更新默认配置；全局工具、搜索、工作目录等设置修改时重建下一次任务的配置。
- Fluent 工具面板、对话状态与设置说明更新为继承语义，不增加额外的继承开关。

## 使用方式

当前运行中的旧进程不会自动加载新代码。退出并重新打开 `dist/AI桌面助手.app` 后，在聊天输入区打开工具设置，启用并保存一次；之后新建对话、切换 Agent 和重启均自动沿用。关闭工具后，后续对话也关闭。不需要逐个 Agent 重新配置。

本轮原生自动验收使用隔离数据和合成 Qt 事件；用户真实窗口中的继承操作仍待实际体验，不将自动验收写作物理操作验收。

本轮尚未提交或推送，不自动修改用户当前工具设置或密钥。
