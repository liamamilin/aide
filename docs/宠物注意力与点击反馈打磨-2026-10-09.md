# 宠物注意力与点击反馈打磨 · 2026-10-09

本轮完成四个现有形象的注意力节奏、工具栏衔接和点击反馈。下文记录本轮交付当时的结果与网络遗留问题。后续已完成[网络生命周期修复验收](Qt网络回复生命周期修复验收-2026-10-09.md)，该问题已关闭，最新体验包以该验收记录为准。

## 体验变化

| 场景 | 现在的行为 |
| --- | --- |
| 刚互动或任务结束 | 闲置动作仍保持 6–12 秒的间隔，回应后恢复自然休息 |
| 长时间没有互动 | 60 秒后逐渐放慢；180 秒后间隔扩大至 18–30 秒。保留每个形象的 7 类闲置动作，自发动作不会重置这段计时 |
| 从宠物移向工具栏 | 工具栏显示、450ms 离开宽限及实际悬停期间保持关注；不会再次播放招呼。收起工具栏或点击操作后正确回到闲置 |
| 按下后移出轮廓或在透明角落松开 | 取消按压姿势，不发出点击；恢复闲置调度。拖动期间的其他鼠标键释放不会提前结束左键拖动 |

实际任务状态仍优先于悬停；减少动态效果保持原有规则。四个形象共享行为，图集和 Petdex 原始配置未变。

## 当时遗留的网络问题（后续已修复）

本轮一次完整回归出现 **1,634 项通过、1 项旧的后台网络压力回归失败**；单独重复原压力用例 12 轮，有 2 轮失败。额外加压复现脚本在最终交付源码上也能复现：模型/搜索任务与大量 QLabel 创建、更新、垃圾回收重叠时，请求偶发返回“连接意外结束”或内部错误。一次诊断中，保存的 Python 回复包装对象已标记失效，而响应头信号的发送者仍对应同一原生地址；失效来源尚未确定。

管理器关联、对象保留和重新查找原生回复等试验方案没有在实际源码的压力复测中稳定消除问题，均已撤回。4 个网络/线程模块及原有 2 份生命周期测试的 SHA-256 与前一轮收尾记录完全一致；最终包未包含这些试验性修复，也未关闭垃圾回收或用请求重试掩盖失败。

已保留[原待办与复现说明](Qt网络回复生命周期待办-2026-10-09.md)及失败输出。后续通过受控地址复用实验定位原因并修复，详见[最新修复验收](Qt网络回复生命周期修复验收-2026-10-09.md)；本页单轮通过仍只代表当时结果。
