# H4 运行审计与历史恢复

日期：2026-10-05。H4 已完成代码、回归和候选包验证。H5 显式工具任务入口尚未开放，普通聊天与 Action 继续使用 `tools=[]`。

## 使用入口与范围

重启最新候选 App 后，在聊天窗口的更多菜单中选择「运行记录…」。可以选择当前会话的运行，查看模型步骤、工具状态、执行详情与搜索来源。页面只读，没有重新执行、批准或停止历史工具的入口。普通聊天与 Action 同样记录运行；升级前的旧会话没有运行记录，不补造历史。

会话导出在当前选中答案之后附加运行记录。删除会话或用户消息会级联删除对应审计记录。聊天历史会恢复选中答案版本自己的来源，不把其他版本同名的 `[S1]` 混入当前答案。

## 存储与身份隔离

数据库升级到 schema 5，升级前仍保存既有备份。

| 表 | 保存内容 |
|---|---|
| `agent_runs` | 会话、用户消息、答案版本、非密钥配置快照、起止时间、终态 |
| `agent_steps` | 有序模型/工具步骤、调用身份、状态、有限元数据、脱敏详情及到期时间 |
| `audit_deletions` | 等待清理受管备份的运行 UUID，不保存正文 |

`RunAudit` 在 GUI 控制线程落库，Worker 只发送带身份的事件。重复事件、其他运行或会话的事件、已关闭步骤的迟到成功以及已删除运行的事件均不会覆盖有效记录。切换会话后，旧 Worker 可完成自己的审计收尾，但不能写入新会话的界面。逐 token 文本事件不逐次写数据库，步骤结束后才保存有限快照。

重启会把未结束的运行标为「已中断」，不会重放命令或搜索。同一进程再次初始化同一数据库不会误中断正在运行的任务。

## 内容保留、脱敏与清理

审计落库前对常见密钥字段、Bearer、部分 token 格式、URL 用户凭据和私钥块做基础掩码；单步 JSON 详情最多 64 KiB。图片只记录数量，不复制 base64。脱敏只作用于审计副本，不修改送给模型的上下文。形态匹配并不完备，不能保证识别任意正文中的秘密。

步骤结束后，参数、模型输入/中间输出、工具输出及来源详情保留 30 天；无正文元数据保留。启动、运行结束及历史查看/导出边界执行幂等清理，活跃运行不会被到期清理。已打开界面的缓存也在访问来源等边界检查到期，过期详情显示说明，引用不再打开。最终答案和原聊天消息继续使用既有聊天保留规则。

清理覆盖当前数据库，以及该数据库目录中受管的 `.schema-` 和 `.before-restore.` SQLite 备份。备份中的未结束运行以原更新时间收尾，避免每次维护重新延长保留期。删除遇到锁定备份时保留 UUID 待重试，全部受管副本完成后才清掉队列；跳过外部命名的副本和符号链接。

本实现没有额外的工具输出文件。SQLite 逻辑删除不等同于物理安全擦除，也不处理用户手动另存或发送的副本。当前产品没有独立的临时会话模式；以后新增时需要复用同一删除路径。
