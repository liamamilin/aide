日期：2026-10-05。本文保留 H3 当时的实现与验收基线；后续已开放全部对话 Agent 显式授权、1–99 来源及历史引用恢复，最新边界见 [冻结应用真实搜索验收](冻结应用真实搜索验收-2026-10-06.md)。下列通用助手限定、5 来源、S30 与尚未实现历史恢复等描述均为历史状态。

原始范围：Parallel / Exa 接入既有 RunLoop / RunWorker；不新增独立调度器，不开放普通聊天工具权限。

## 实际验证

用户填写的两家密钥已保存到 macOS 钥匙串。首次使用生产 SearchJob 分别发出一个最小请求：来源数量 1、超时 30 秒，Parallel 使用 basic，Exa 使用 auto。两家均为 HTTP 200，返回 Python 官方文档来源，耗时 2.293 秒 / 4.824 秒。[供应商验证记录](harness-h3/providers-2026-10-05.json)只保留服务名、HTTP 状态、时间、标题和 URL，不含密钥、原始响应或摘要。

随后在本机 Ollama 0.34.3、qwen3.5:9b-mlx 上，分别完成真实 RunWorker → 模型工具调用 → 搜索 HTTP → 工具回填 → 模型回答闭环。参数为 think=false、num_ctx=8192、num_predict=1024、temperature=0；每个样本最多 2 轮模型、1 次工具、1 次搜索、60 秒活动时间。两家均 succeeded，回答包含 `[S1]`，总耗时 10.450 秒 / 8.367 秒，搜索为 2.208 秒 / 5.174 秒。模型 digest、参数及脱敏结果见[闭环记录](harness-h3/runtime-2026-10-05.json)。这些是两次受限冒烟，不代表长期可靠性或性能基准。

本轮总计 **4 次付费搜索请求**（每家 2 次），没有自动重试、切换供应商或下载模型。自动测试全部使用本机模拟 HTTP 服务；构建冒烟不读取真实凭据、不调用付费服务。

## 运行时边界

- SearchSettings 在创建任务时冻结 provider、来源数、超时和 Parallel mode；任务期间修改全局设置不会改变快照。请求元数据只保存非秘密参数。
- SearchExecutor 由 RunWorker 持有；仅显式准入的通用助手聊天可以注册 web_search。Action、其他角色、默认聊天保持空工具路径，不构造搜索执行器、不读取钥匙串。
- 模型只能提供 query / objective，不能选择供应商、密钥、端点、模式或超时。密钥首次搜索时按供应商读取一次，任务内仅存内存；后台读取禁止原生交互提示。缺失、钥匙串不可访问、参数无效回填有限错误，不发 HTTP。需要钥匙串授权时回设置重新保存，不让后台任务等待系统弹窗。
- 搜索使用工作线程自身的 Qt 网络事件循环；取消与活动截止每 20 毫秒检查一次并中断连接。供应商超时单独计时，取消后不启动下一轮模型。沿用每任务最多 6 次搜索、16 次工具、8 轮模型和 300 秒活动预算。
- 不继承代理、不跟随重定向、不自动重试或切换供应商；鉴权、额度、限流、网络、协议、响应上限有明确错误类别。响应最多 2 MiB，每次最多 5 个来源。

接口依据：[Parallel Search 官方 API](https://docs.parallel.ai/api-reference/search/search)、[Exa Search 官方 API](https://exa.ai/docs/reference/search)。Parallel 使用 search_queries / mode / max_chars_total；Exa 使用 query / type=auto / numResults / contents.highlights。两者均支持可选 objective；没有新增提取、浏览或共享搜索会话。

## 来源与表现层

工具结果为有效 JSON，含 provider、retrieved_at、duration、truncated、error_type、error 和 sources。来源保留标题、原 URL、摘要、发布日期；编号在整个任务内连续使用 S1–S30，不因下一次搜索重置。只有实际包含在工具输出内的来源进入来源表。

默认输出不超过 **4096 UTF-8 字节**：先均匀缩短摘要，再缩短标题，最后移除完整来源；保留有效 JSON 和完整 URL，标记 truncated。单个 URL 无法装入预算时移除该来源，避免错误链接。后续上下文缩减由 RunLoop 处理，不重复搜索。

Fluent 卡片展示搜索词、进度、来源数量、供应商和耗时，可展开摘要、打开来源；搜索不显示本地命令工作区。标题和摘录为纯文本。错误、停止、无结果与截断有可见反馈，复用既有停止按钮及任务身份过滤。

最终回答中的 `[S1]` 等编号，只有匹配该回答自己的真实来源表时才可点击。内部 source://ID 点击时解析原 URL，仅允许无内嵌账号的 HTTP/HTTPS。未知编号保留文字，模型自带 URL 或 HTML 不获得链接权限，行内/围栏代码不转换引用。不同任务不共享编号；主题重绘保留回答来源表，清空对话和开始新回答清除活动表。

工具描述明确网页结果是数据而非指令，并要求引用返回的编号。这不能保证模型不会受网页文字影响，也不证明每条引用都语义正确。
