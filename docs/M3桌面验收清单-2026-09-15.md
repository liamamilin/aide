# M3 桌面验收清单

版本：`1.5.0` arm64 候选  
候选包：[AI桌面助手.app](../dist/AI桌面助手.app)  
DMG：[AI桌面助手-1.5.0.dmg](../dist/AI桌面助手-1.5.0.dmg)  
记录日期：2026-09-22

当前 DMG 仍是早前候选；本轮宠物交互与空选区反馈只重建了 `.app`，尚未更新 DMG。

本清单用于真实 macOS 桌面验收。自动化测试和隔离冒烟不能代替系统权限、真实焦点、Spaces 和多屏操作，因此手动项目需要在退出旧实例后使用最新候选包执行。

## 使用前

- [ ] 退出旧版 AI 桌面助手进程。
- [ ] 从最新 `.app` 启动，确认菜单栏图标和猫头鹰宠物出现。
- [ ] 若系统再次提示权限，只对最新稳定签名候选授权；记录授权项和是否需要重启。

## F04：重新生成与版本切换

- [ ] 发送一条普通问题，确认最后一条助手回复出现“重新生成”入口。
- [ ] 点击重新生成，确认旧答案保留，新答案作为同题新版本出现。
- [ ] 打开版本入口，确认只显示成功且有内容的版本。
- [ ] 切换版本后复制，确认复制的是当前可见版本。
- [ ] 在切换后继续追问，确认上下文使用当前版本。
- [ ] 生成中取消或失败，确认旧成功答案仍可切换，失败版本不可设为当前。

## F01：中文选区与截图快捷键

- [ ] 在文本编辑器或浏览器选择中文，按 `⌘⌃L`，确认动作面板显示正确中文。
- [ ] 选择“翻译”，确认材料填入输入框且可发送；执行后面板保持展开。
- [ ] 按 `⌘⌃S` 框选区域，确认截图授权、取消和成功路径均有明确反馈。
- [ ] 对截图执行 OCR 或发送图片，确认中文不乱码；测试中文输入法候选确认不会误发送。

## F02：OCR 与图片处理

- [ ] 截图后选择“仅文字”，确认请求不携带原图。
- [ ] 截图后选择“文字 + 原图”，确认编辑后的文字和图片一起进入草稿。
- [ ] 移除图片、关闭预览、取消识别，确认窗口不阻塞且输入可恢复。
- [ ] 使用非视觉模型时，确认界面明确提示仅文字路径。

## F13：宠物、焦点与多屏

- [ ] 右键宠物选择“隐藏桌面宠物”，确认宠物和结果气泡消失。
- [ ] 点击菜单栏图标，确认出现“显示桌面宠物”，点击后宠物恢复原位置。
- [ ] 切换紧凑悬浮球模式，确认菜单文案变为“隐藏/显示悬浮球”。
- [ ] 拖动宠物到屏幕边缘，切换 Spaces 或外接屏，再确认位置仍在可见区域。
- [ ] 在宠物、对话框、设置、历史窗口之间切换焦点，确认自动收起不会误关闭所属子窗口。
- [ ] 浅色/深色模式切换后，确认对话、菜单、气泡和输入框可读。
- [ ] 闲置约 10 分钟，观察无持续高 CPU、窗口无残影或重复绘制。
- [ ] 右键“朗读选区”但没有选中文字，确认出现非阻塞宠物旁提示；宠物隐藏时确认回退菜单栏通知。
- [ ] 用最新裁剪包选中英文单词和句子并朗读，确认首次模型加载、真实发声、停止朗读与再次朗读正常。
