# Agent 工具通用化后续计划

日期：2026-10-05，更新：2026-10-06。第一、二阶段实现已接入，真实 9B / 27B 六角色 Bash 闭环通过，见 [对话 Agent 工具通用化](对话Agent工具通用化-2026-10-06.md)。第三阶段已完成来源数量、取消清理、冻结凭据阻塞、答案裁切及自签名钥匙串分区失配修复；当前固定签名助手在主 App 签名变化后保持身份，两家现有密钥后台可读，最新冻结 27B Parallel / Exa 真实搜索及新历史标签验收均通过，最终全量 1275 项，详见[真实搜索验收](冻结应用真实搜索验收-2026-10-06.md)。当前优先转向真实桌面选区/快捷键、焦点、多屏/Spaces 与安装升级验收，随后发布收尾。

## 第一阶段：工具能力开放到所有对话 Agent

目标：内置和自定义 Agent 都能在当前对话显式启用 Bash / Parallel / Exa，复用现有工具循环、工作区、确认、审计和取消实现，不增加另一套 Agent 执行器。

- 移除工具入口、发送、重试和能力检查中对 general_assistant 的硬编码限制。
- 保留各 Agent 的角色提示词；仅在工具已授权时加入公共工具使用规则，不把所有角色替换成通用助手，也不强制每个回答调用工具。
- 每个新对话默认关闭工具，切换 Agent 继续清除授权；同一 Agent/对话切换模型保留工具勾选，下一轮检查并使用新模型。快捷动作继续是无工具流程。
- 顶栏所选模型是工具运行的模型来源；普通聊天保留现有 profile 解析。工具模式不通过 Agent profile 悄悄换模型，界面说明两种配置的适用范围。已完成的 [参数一致性修复](工具模型参数一致性修复-2026-10-05.md) 应继续复用：上下文与采样参数跟随设置，角色思考/温度/输出覆盖有效；不可重新引入固定工具参数。
- 先沿用全局工具入口开关，不增加每个 Agent 的独立权限矩阵或自动授权设置。将“允许通用助手启用工具”改为所有对话 Agent 的准确说明，兼容旧设置值。

验收：至少覆盖通用助手、代码角色、一个文本角色和一个自定义 Agent 的实际 HTTP 模型/工具/角色提示词；核对停止、重新执行、授权清除、新旧请求隔离及真实模型工具闭环。

## 第二阶段：统一设置与反馈

- 明确区分“模型支持工具”“当前对话已授权工具”“正在执行工具”；授权状态不能冒充能力验证结果。
- 授权面板始终显示当前模型、工具勾选、目录/策略和搜索供应商；失败提示说明是模型能力、连接、目录还是凭据问题，并保留材料。
- 保持 Fluent 默认组件和现有页面结构；只调整必要的文案与分组，不新增大量采样/调度参数，不替换整个设置系统。
- 取消或模型切换后恢复可操作状态，过程卡片和历史记录仍对应真实模型与 Agent。

验收：窄窗布局、键盘操作、检查中/失败/取消状态，及旧设置迁移；无模态警告循环或静默模型回退。

## 第三阶段：跨 Agent 与搜索完整流程验收

当前完成：固定签名原生凭据助手、独立调用方校验、免费连接和无提示复核，合成条目跨不同原生程序及打包 App 签名变化验证通过，最终全量 1275 项。Parallel / Exa 现有条目均可后台读取，用户批准的冻结 27B 两家各一次真实搜索、引用及新历史标签恢复均通过。详情见[修复说明](搜索凭据跨构建稳定修复-2026-10-06.md)。现有真实条目通过正常系统授权访问，不进行代码迁移；不自动扩大 ACL 或用源码密钥注入 App。不得把此前的“稳定证书”视为钥匙串升级授权已验证。

- 使用本机 9B 和 27B，检查不同角色的 Bash 读取、需要确认的命令、切换 Agent/模型及新对话。
- 已补 Parallel / Exa 最新冻结 27B 的模型→搜索→来源→最终引用完整链路；各一次 HTTP 200，记录有限请求次数，不输出密钥。
- 出错场景包括不支持工具的模型、搜索失败、无效目录、命令拒绝、生成/执行中停止，以及重启后历史只读。
- 只有新增问题或代码变更需要时扩大测试；保留已有源码、模拟服务和冻结包证据的区别。

## 第四阶段：桌面与发布收尾

完成真实选区/全局快捷键、截图权限、跨应用焦点、多屏/Spaces 和覆盖安装检查。重建稳定签名候选、核对包内源码和文档。根据验收结果决定是否提交、推送或发布；发布动作需按用户后续指令进行。

范围：本阶段继续只用 Bash 和联网搜索；不新增多 Agent 并行、自动后台任务、长期记忆、知识库或更多工具。实际发现的问题优先于新增功能，开发过程继续记录到 [开发进度](开发进度.md)。
