# Harness 冻结应用真实流程验收

更新日期：2026-10-05。接续 [源码真实任务验收](Harness真实任务验收与稳定性修复-2026-10-05.md)，本轮验证冻结应用中的原生 UI、真实本机模型调用和新进程历史恢复。候选版本仍为 `1.5.0`。

## 实现

[验收启动器](../scripts/harness_acceptance.py) 支持 `--packaged`，可传 `.app` 或包内可执行文件。启动器建立 `aide-acceptance-*` 临时目录，在启动子进程前设置独立的数据和日志环境。验收模块检查根目录位置及名称、数据/日志的实际解析路径和已导入的数据库路径；缺失或不匹配直接失败。命令完成后清理临时目录，预设测试结果和窗口预览可保留到指定输出目录。

验收逻辑位于 [diagnostics 模块](../ai_desktop/diagnostics/harness_acceptance.py)，只由显式 `--harness-acceptance` 入口加载。冻结应用使用当前入口的 ChatController；重启探针调用同一个冻结可执行文件，源码模式调用 Python 模块。正常启动、工具授权和用户数据库流程不变，没有新增产品页面或常驻监听。

真实模型使用本机已准入的 9B：普通聊天/动作采用 think=false、8192 上下文、512 输出；工具任务继续由 H5 逐次检查版本与 digest，使用准入的 8192/1024 参数。测试没有读取搜索密钥、调用付费搜索或触发权限申请。Bash 仅批准预设临时写入命令，意外命令拒绝并停止。

## 验收范围

| 范围 | 检查 |
|---|---|
| 窗口 | 400×460、520×800 原生布局，输入/发送控件可见且在窗口内，放大/恢复，缩放/默认恢复，草稿保留 |
| 聊天 | 首次发送、重新生成、答案版本、无重复用户消息、无工具 |
| 动作 | 翻译/解释/摘要/改写 × 当前/新对话，动作规则/profile、重新生成、空工具 |
| Bash | 只读临时文件、批准后写入、拒绝不写入、等待中隐藏取消 |
| 会话隔离 | 生成中取消、新会话、授权清空、旧任务取消记录 |
| 重启 | 新进程加载本轮保存的历史，不执行工具、不恢复授权，合成未完成运行标为 interrupted |

窗口预览来自 QWidget 自身渲染，未调用系统截图 API。原生窗口操作不等同于用户物理点击、跨应用焦点、全局快捷键或多屏/Spaces 验收。当前 UI 使用组件库默认 Fluent Light；此轮不新增深色主题。

## 运行方式

在项目根目录执行：

```sh
python3 scripts/harness_acceptance.py \
  --packaged dist/AI桌面助手.app \
  --output /tmp/aide-packaged-acceptance/result.json
```

可追加 `--only window_layout_and_restore` 或 `--only restart_and_readonly_history` 做专项检查。单独重启检查使用合成历史、不调用真实模型；完整流程的重启检查加载本轮真实模型保存的会话，并另外构造一个未完成运行。
